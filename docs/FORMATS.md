# Форматы данных «Как достать соседа» (Neighbours from Hell 1)

Проверено на русском издании (Бука / JoWooD), папка `Как достать соседа Сладкая месть`.

## Раскладка установки

```
bin/   game.exe, GFXEngine.dll, SFXEngine.dll, Loader.dll, mss32.dll (Miles Sound System)
data/  gamedata.bnd     207 XML    — уровни, объекты, анимации, строки, меню
       gfxdata.bnd     4337 TGA    — спрайты и фоны (≈184 MiB в распакованном виде)
       sfxdatahigh.bnd  289 файлов — 13 mp3 (музыка) + 276 wav (эффекты), высокое качество
       sfxdata.bnd      289 файлов — то же самое в низком качестве
       *.ttf / *.fot           — шрифты (A.C.M.E. Secret Agent, Blue Highway)
       game.xml                — заголовок окна и папка сохранений (AppData/JoWooD/BukaNfH)
```

## .bnd — это обычный ZIP

* Сигнатуры `PK\3\4` / `PK\1\2` / `PK\5\6`, без шифрования и без ZIP64.
* Методы сжатия: 0 (stored — mp3/wav) и 8 (deflate — xml/tga).
* Пути в ASCII, разделитель `/`, регистр букв непоследовательный
  (`woody/W_clock_0000.tga`), поэтому поиск файлов делается без учёта регистра.

## TGA — нестандартные 16-битные форматы

Все файлы — несжатый true-color TGA (type 2), 16 бит на пиксель, начало координат вверху слева.
Отличие от стандарта в том, как игра трактует биты альфы в байте дескриптора (смещение 17):

| дескриптор | файлов | реальный формат | где используется |
|---|---|---|---|
| `0x24` (4 бита альфы) | 4259 | **ARGB4444** | персонажи, предметы, анимации |
| `0x20` (0 бит альфы) | 77 | **RGB565** (а не X1R5G5B5) | фоны домов, GUI |
| 24 бит, `0x00` | 1 | BGR24, начало внизу | `loading.tga` |

Обычные редакторы читают `0x20` как 555, поэтому фоны выглядят фиолетово-зелёными.
Отсюда и «специфический альфа-канал», о котором пишут моддеры.

## XML

Кодировки бывают разные, это надо определять для каждого файла:

* **UTF-16LE с BOM** — `strings.xml`, `leveldata.xml`, `fonts.xml`, диалоги;
* **ASCII** — `anims.xml`, `objects.xml`, `gfxdata.xml`, `sfxdata.xml`, `trigger.xml`, …;
* **8-бит (cp1252)** — `level.xml` в 13 уровнях (немецкие комментарии разработчиков).

Файлы не всегда корректные XML: например, у `gfxdata.xml` несколько корневых элементов.

### Структура уровня (`gamedata/<level>/`)

| файл | содержимое |
|---|---|
| `level.xml` | размер дома, комнаты (`room`: offset, path1/path2, `floor`, `door`, `neighbor` — граф переходов со стоимостью), стартовые позиции актёров, слои |
| `objects.xml` | интерактивные объекты, их состояния и действия |
| `anims.xml` | для каждого объекта: `region` (хитбокс), `animation` с кадрами `frame gfx=… sfx=…` |
| `gfxdata.xml` | для каждого объекта: список картинок с `offset="x/y"` (позиция кадра) |
| `sfxdata.xml` | звуки уровня |
| `tricks.xml` | пакости и очки за них |
| `combine.xml` | комбинации предметов |
| `trigger.xml` | триггеры |
| `strings.xml` | локализованные названия (`name`, `category`, `text`) |

`generic/` содержит общие для всех уровней данные: Вуди, сосед, Чили, собака, двери.

`leveldata.xml` описывает эпизоды (`set`) и уровни: `minquota` — минимальный процент,
`time` — лимит времени (в тиках), `reachable` — сколько пакостей доступно.
