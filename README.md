# OpenNFH

Кроссплатформенный (Linux / Windows) движок и набор утилит на C++17 и SDL2 для оригинальной игры **«Как достать соседа»** (*Neighbours from Hell 1*). Работает напрямую с оригинальными архивами `.bnd` из установленной копии игры.

## Что реализовано

### Этап 1 — Ядро и инструменты работы с ресурсами
* **`nfhcore`** — библиотека чтения ресурсов игры:
  * Чтение архивов `.bnd` (`gamedata.bnd`, `gfxdata.bnd`, `sfxdata.bnd`, `sfxdatahigh.bnd`) напрямую без предварительной распаковки и без чувствительности к регистру имён файлов (важно для Linux).
  * Декодер проприетарных 16-битных `.tga` текстур игры: **ARGB4444** (дескриптор `0x24`, спрайты с альфа-каналом) и **RGB565** (дескриптор `0x20`, фоны домов и интерфейс — без фиолетово-зелёных артефактов стандартных редакторов), а также 24/32-битных и RLE TGA.
  * Автоопределение кодировок игровых `.xml` (`UTF-16LE`, `UTF-8`, `Windows-1251` / `Windows-1252`) с конвертацией в `UTF-8` и нестрогий XML-парсер, понимающий файлы с несколькими корневыми тегами (`gfxdata.xml`).
* **`nfh-extract`** — консольная утилита для просмотра списка ресурсов, извлечения и конвертации (`.tga` → `.png`, `.xml` → `UTF-8`).
* **`nfh-viewer`** — графический просмотрщик ресурсов на SDL2 (спрайты, покадровые анимации с авто-стабилизацией по `offset`, звуки `.wav`/`.mp3`, XML, шрифты `.ttf`).

### Этап 2 — Игровой движок (`opennfh`)
* Загрузка всех 17 уровней оригинальной игры из `gamedata/leveldata.xml` (объединение базовых ресурсов `generic/*.xml` с данными конкретного уровня `<level>/*.xml`).
* Попиксельный рендер дома в разрезе, всех комнат, дверей, интерактивных объектов, Вуди и Соседа по оригинальным координатам `offset`/`hotspot`.
* Навигация Вуди между комнатами с поиском кратчайшего пути через двери (BFS по графу `<neighbor>` из `level.xml`), ходьба (ЛКМ) и подкрадывание (ПКМ / двойной клик).
* Обыск контейнеров (аптечка, комод, мусорное ведро, микроволновка, холодильник и т.д.), сбор предметов в инвентарь и укрытия (шкаф и под кроватью).
* Установка ловушек и комбинаций предметов из `combine.xml` и `tricks.xml` с индикатором прогресса.
* ИИ Соседа: обход маршрута по дому, облачко мыслей над головой с иконкой следующего действия, срабатывание пакостей с анимациями ярости, начислением рейтинга и бонусами за комбо.
* Система обнаружения: если Сосед застаёт Вуди в одной комнате, воспроизводится сцена драки в облаке пыли (`kill1`), после чего Вуди возвращается на крыльцо.
* Оригинальный нижний интерфейс (HUD 800×600): портрет Соседа, шкала ярости, слоты инвентаря, будильник с таймером, счётчик пакостей и процент зрительского рейтинга.

Описание форматов файлов игры находится в [docs/FORMATS.md](docs/FORMATS.md).

## Сборка и запуск на Linux

### Вариант А — Готовая сборка из GitHub Releases / Actions (без компиляции)

При каждом пуше в репозиторий GitHub Actions ([`.github/workflows/build.yml`](.github/workflows/build.yml)) автоматически собирает Linux-бинарники (`x86_64`) и публикует архив **`opennfh-linux-x86_64.tar.gz`** во вкладке **Releases** (тег `latest-linux`) и в артефактах **Actions**.

1. Установите системные библиотеки SDL2 (один раз):
   ```bash
   sudo apt update && sudo apt install -y libsdl2-2.0-0 libsdl2-ttf-2.0-0 libsdl2-mixer-2.0-0 zlib1g fonts-dejavu-core
   ```
2. Распакуйте скачанный архив и запустите игру, указав папку с установленной оригинальной игрой (где лежит `data/gamedata.bnd`):
   ```bash
   tar -xzf opennfh-linux-x86_64.tar.gz
   cd opennfh-linux-x86_64
   ./opennfh --game "/путь/к/Как достать соседа"
   ```

### Вариант Б — Самостоятельная сборка из исходников на Linux

#### 1. Установка зависимостей

**Ubuntu / Debian / Linux Mint:**
```bash
sudo apt update
sudo apt install build-essential cmake ninja-build pkg-config \
                 zlib1g-dev libsdl2-dev libsdl2-ttf-dev libsdl2-mixer-dev \
                 fonts-dejavu-core
```

**Arch Linux / Manjaro:**
```bash
sudo pacman -S base-devel cmake ninja pkgconf zlib sdl2 sdl2_ttf sdl2_mixer ttf-dejavu
```

**Fedora:**
```bash
sudo dnf install gcc-c++ cmake ninja-build pkgconf-pkg-config \
                 zlib-devel SDL2-devel SDL2_ttf-devel SDL2_mixer-devel \
                 dejavu-sans-fonts dejavu-sans-mono-fonts
```

#### 2. Сборка

```bash
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release
cmake --build build
```

Исполняемые файлы появятся в папке `build/`:
* `./build/opennfh` — **игровой движок**
* `./build/nfh-viewer` — просмотрщик ресурсов
* `./build/nfh-extract` — консольный распаковщик

## Сборка и запуск на Windows (MSYS2 UCRT64 / VSCode)

В проект добавлены настройки `.vscode/` — откройте папку проекта в **VSCode**:
* `F5` — собрать и запустить игру **`opennfh`** (или выберите `nfh-viewer` в выпадающем списке панели Run and Debug).

## Управление в игре (`opennfh`)

```bash
./build/opennfh
# или сразу конкретный уровень:
./build/opennfh --level level_pie
```

* **ЛКМ по полу / двери** — идти в указанную точку или перейти в другую комнату (Вуди сам откроет нужные двери по пути).
* **ПКМ по полу (или двойной клик ЛКМ)** — красться на цыпочках.
* **ЛКМ по шкафу / комоду / аптечке / холодильнику** — обыскать и взять предмет (или спрятаться в шкафу; повторный клик — выйти из укрытия).
* **ЛКМ по предмету в инвентаре (внизу) → ЛКМ по объекту в комнате** — применить предмет и устроить пакость (также можно просто кликнуть ЛКМ по целевому объекту, если нужный предмет уже есть в инвентаре).
* **ПКМ** — снять выделение с выбранного предмета инвентаря.
* **`[` / `]`** — переключить предыдущий / следующий уровень (все 17 уровней).
* **`V` или `Tab`** — переключить камеру: **Весь дом целиком** / **Следовать за Вуди**.
* **`F11` или `T`** — переключить полноэкранный режим.
* **`R`** — перезапустить текущий уровень (с диалогом подтверждения).
* **`H`** — показать/скрыть отладочные зоны клика (хитбоксы объектов и дверей).
* **`Space`** — пауза.
* **Стрелки / `W` `A` `S` `D` / зажатая СКМ** — ручной сдвиг камеры.

## Инструменты Этапа 1 (`nfh-viewer` и `nfh-extract`)

### Графический просмотрщик (`nfh-viewer`)

```bash
./build/nfh-viewer --game "/путь/к/Как достать соседа"
```

* `↑` / `↓` / `PgUp` / `PgDn` / `Home` / `End` или клик мыши — выбор файла.
* `Ctrl+F` или `/` — поиск по имени файла (`Esc` — сбросить фильтр).
* `Space` — запуск/пауза анимации (для кадров `*_0000.tga`) или воспроизведение звука (`.wav`/`.mp3`).
* `←` / `→` — предыдущий/следующий кадр анимации; `[` / `]` — скорость (`fps`).
* Колесо мыши, `+` / `-`, перетаскивание ЛКМ — масштаб и сдвиг картинки (`1` — 100%, `2` — 200%, `F` — вписать в окно, `B` — шахматный/чёрный фон).

### Консольный распаковщик (`nfh-extract`)

```bash
./build/nfh-extract info
./build/nfh-extract list woody
./build/nfh-extract cat gamedata/level_pie/level.xml
./build/nfh-extract extract ./unpacked
```
